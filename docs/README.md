# RemiCare Frontend Documentation

Frontend documentation is organized by purpose:

- `reports/`: audits, phase reports, research notes, cleanup candidates, and prompts moved out of the project root.
- `phases/`: phase handoff documentation.
- root `README.md` remains at the project root for quick setup and deployment context.

Runtime source files remain in `src/`, `public/`, `api/`, and deployment config files at the project root.
